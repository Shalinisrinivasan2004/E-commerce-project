E-Commerce Web Application

A simple E-Commerce web application developed using Java and Spring Boot.

Technologies Used

- Java
- Spring Boot
- Maven
- SQL
- Docker

Project Structure

- "src/main/java" – Application source code
- "src/main/resources" – Application configuration
- "src/test" – Test cases
- "pom.xml" – Maven dependencies and project configuration
- "docker-compose.yml" – Docker configuration
- ".gitignore" – Git ignored files

Features

- E-Commerce application backend
- Spring Boot based application
- Maven-based project setup
- Database configuration
- Unit testing

How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Make sure Java and Maven are installed.
4. Configure the database in "application.properties".
5. Run the Spring Boot application.
